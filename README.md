# Site do RH — Brutal Acabamentos

Site institucional do Recursos Humanos e Departamento Pessoal da Brutal Acabamentos:
vagas abertas, serviços do RH e informações para colaboradores.

## Estrutura

```
index.html      Página principal
css/style.css   Estilos
js/main.js      Comportamentos (menu mobile, ano do rodapé)
img/            Logotipo e fotos da equipe
```

## Tecnologia

HTML, CSS e JavaScript puros, sem frameworks e sem etapa de build.
Funciona direto no GitHub Pages a partir da raiz do repositório.

## Pendências (marcadas como `[PREENCHER]` no site)

- Dia de pagamento e regras de adiantamento salarial
- Prazo médio do processo seletivo e informações sobre aprendiz/estágio
- Contatos: Instagram, LinkedIn e endereço
